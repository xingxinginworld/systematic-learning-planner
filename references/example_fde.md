# 示例：以 FDE（前线部署工程师）学习跑通本技能

> 类型：贯穿示例 · 用途：展示 8 步各自该产出什么 · 配套样板：`references/example_fde/`

本示例展示如何用本技能把「FDE 学习」从需求澄清做到端到端毕业方案。为便于携带，技能**仅内置最小结构样板**（`references/example_fde/`）：

- `00-总览.md`：阶段 / 周次导航 + 学习原则
- `week-01.md`：一张周卡片样例（目标 / 每日拆分 / 实战产出 / 资源 / 自检）
- `周模板.md` / `日模板.md`：可复用记录模板

> 完整 18 周规划、`FDE学习规划.md` 主规划、`资源索引.md`、`build_fde_scaffold.py` 脚手架生成器保留在作者原项目（未随技能分发）。本文件只说明「每一步该产出什么」，样板目录给的是结构形态。

当你不确定某一步该产出什么时，对照本文件与 `references/example_fde/` 下的样板即可。

## 各步在 FDE 上的产物对照

**步骤 1 需求澄清**
用户确认：FDE = 前线部署工程师（AI 落地交付岗）/ 背景 = 10 年 AI PM 交付 / 目标 = 能力补强服务现职（不转岗）/ 时间 = 5–8 小时·周 / 周期 = 18 周 / 侧重 = 技术底座 + RAG·Agent，避开 = 纯算法。

**步骤 2 摸底测试**
围绕 FDE 8 类能力模型出题：全栈工程 / LLM 应用 / RAG / Agent / 系统集成 / 评测安全 / 业务分析 / 客户交付，区分零基础→高级。

**步骤 3 水平评估**
《摸底评估报告》结论：S = 交付强项（L7–L8 已熟）；W = TS/Next.js/RAG/Agent/LangGraph 未体系化；判定 = 中级偏交付型。优先短板 = 技术左半边（L1–L6）。

**步骤 4 路径规划**
输出 6 阶段 18 章式目录：工程底座 → LLM 应用 → RAG → Agent → 集成评测 → 交付毕业。（完整总表见作者原项目 `FDE学习规划.md` 第 4 节；技能内置 `references/example_fde/00-总览.md` 展示导航结构。）

**步骤 5 执行计划拆解（周/日 + 里程碑）**
把路径拆成 week/day 计划 + 里程碑，落地为「周卡片 + 日模板」文件结构。技能内置的 `references/example_fde/` 即该结构的样板：`week-01.md` 是一张完整周卡，`周模板.md`/`日模板.md` 是可复用的空模板。

**步骤 6 单节内容生成**
每张 `week-NN.md` 即「单节配套内容」的周级形态：含本周目标、每日拆分、实战产出、精选资源、周末自检——对应提示词 005 的 6 板块（目标/资料/知识点/案例/速查表/测验），只是粒度放大到周。

**步骤 7 总复习**
W16–W18 毕业项目 + 作品集 + 答辩材料，闭合学习循环；可附《核心知识地图》《综合模拟测验》《速查索引》。

**步骤 8 复测闭环**
用 FDE 8 类能力模型复测，评价是否达成「独立把 AI 项目从需求做到生产」，并决定对 RAG / Agent 做专项补强（回到步骤 3/4）。

## 关键经验（可复用到任意主题）
- 技术/工程类主题：用「周卡片 + 日模板」文件结构落地执行计划，比纯文档更易坚持。
- 真实场景驱动：毕业项目直接复用用户手上已有素材（如 FDE 的评标 Agent / 企业知识库），避免虚构。
- 强项做杠杆：把用户已强的环节（如 FDE 的交付/ROI）精炼，把弱点（技术底座）前置猛攻。
- 里程碑审批：每 2–4 周一个检查点，先确认再继续，符合「先思考、规划，我确认后执行」。
