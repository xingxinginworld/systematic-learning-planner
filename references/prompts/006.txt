# Step 006 · 执行计划拆解（Execution Plan）
> 用途：把路径拆成 week/day 计划 + 里程碑，附弹性缓冲
> 输入：004 路径目录 · {可投入时间} · {总周期}
> 输出：week/day 计划 + 里程碑（HTML，可复制/下载）
> 依赖：004（路径规划）→ 本步 → 005（每日内容）

基于已确认的学习路径目录（见步骤 4 输出）和我的可投入时间（{可投入时间}，总周期 {总周期}），请将整条路径拆解为可执行的「执行计划」。

要求：
1. 以周为单位排期：把每一章/节的学时分配到具体周次（如 W1：第1章 1.1–1.3；W2：第1章 1.4–1.6 + 第2章 2.1…），形成连续无断点的时间表。
2. 每周给出四要素：
   - 本周目标（1–3 条可衡量）
   - 每日拆分（约 {每天小时} 小时/天，周末留弹性）
   - 实战产出/练习（必须能演示或提交，禁止"只看不练"）
   - 周末自检清单（打勾项）
3. 设定里程碑：每 2–4 周一个检查点，明确该里程碑的「完成标准」（可演示 / 可测验 / 可交付文档）。
4. 弹性机制：标注若某周时间不足，哪些节可平移到缓冲周，避免"中断即失败"。
5. 工程/技术类主题：推荐用「周卡片 + 日模板」文件结构落地（参考本技能 `references/example_fde/` 的结构样板：00-总览 / week-01 / 周模板 / 日模板），每周一个 markdown 卡片。
6. 总览用 HTML 呈现，并提供可复制/下载的周计划清单。

请开始生成执行计划。先思考、规划，我确认后执行。
