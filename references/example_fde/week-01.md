# 第 01 周 · 开发环境与 TypeScript 基础

> 阶段：A. 工程底座 ｜ 建议投入：5–8 小时

## 一、本周目标
- 搭好稳定的本地开发环境（Node/pnpm/Git/终端）
- 掌握 TypeScript 类型系统，能用 TS 写带类型的脚本
- 补齐现代前端三件套（HTML/CSS/ES2022）认知

## 二、每日拆分（约 1 小时/天，周末留弹性）
- D1 环境搭建：Node(pnpm) / Git / VS Code / 终端；顺手复盘你已有的 Python venv 流程
- D2 TS 基础：类型、接口 interface、泛型、模块与导入
- D3 TS 进阶：异步 async/await、tsconfig 配置、类型体操入门
- D4 前端三件套速通：语义化 HTML / 现代 CSS / ES2022 新特性
- D5 小练习：用 TS 写一个 CLI 小工具（如按规则自动归类文件）
- D6 周复盘：写 200 字本周笔记 + 提交到 Git

## 三、实战产出
一个可运行的 TS CLI 小工具（带类型、可 npm 安装）

## 四、精选资源
- TypeScript 官方手册 https://www.typescriptlang.org/docs/
- Node.js 文档 https://nodejs.org/docs/latest/api/
- pnpm 文档 https://pnpm.io/zh/

## 五、周末自检
- 能独立用 TS 写带类型的脚本并编译运行
- 理解 interface / 泛型 / 异步的基本用法
